# Education Website Template  
### Built with HTML, Advanced CSS & jQuery

A clean, modern, and responsive **Education / Learning / School website template** created using **HTML5**, **advanced CSS3**, and **jQuery** for interactive features.  
Suitable for online courses, coaching centers, schools, colleges, or any educational platform.

---

## 🎓 Features
- Responsive homepage layout  
- Advanced CSS animations & transitions  
- jQuery-based menu interactions  
- Course cards grid  
- Category filters  
- Testimonials section  
- Modern header & footer  
- Clean, organized code structure
